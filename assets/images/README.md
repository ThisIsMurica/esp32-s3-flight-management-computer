# FMC prototype photographs

This directory holds original photographs of the ESP32-S3 flight-management computer, its Feather sensor computer, and prototype interface/field tests.

The photographs document development work, not flight-certified instrumentation or current operational navigation data. Screens displaying AIRAC cycle 2608 represent a historical development snapshot.

Expected image filenames:
- `fmc-night-navigation.jpg` — field demonstration of the LAT/LON navigation interface
- `fmc-system-status.jpg` — diagnostics/status screen and hardware setup
- `fmc-live-navigation.jpg` — outdoor navigation display with sensor hardware
- `feather-sensor-bench.jpg` — electronics workbench and sensor-computer setup
- `fmc-progress-page.jpg` — GPS/navigation progress display
